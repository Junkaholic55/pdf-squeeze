# PDF Squeeze

A portable Windows app that makes PDFs with pictures smaller.
It needs no installer and no admin rights: unzip it and drag a PDF onto `PDFSqueeze.exe`.

## What it does

PDF Squeeze rewrites only the images in a PDF.
Text, fonts, links, bookmarks and forms are left exactly as they are, so text stays selectable and searchable.

For each image it:

1. Works out the image's real resolution on the page, by following the page's drawing instructions, including nested Form XObjects.
2. Downsamples it to the chosen level's target DPI if it is more than 10% above it.
3. Re-encodes it: photos and scans as JPEG (grayscale when the image is gray), and flat graphics such as charts and screenshots losslessly with a color palette.
CMYK images stay CMYK, so colors don't shift.
4. Keeps the new version only if it is at least 10% smaller.

It leaves alone the image types it can't improve safely: 1-bit black-and-white scans (CCITT/JBIG2), stencil and color-key masks, 16-bit images, and unusual color spaces.

| Level | Target DPI | JPEG quality |
|---|---|---|
| High quality | 200 | 85 |
| Balanced | 150 | 72 |
| Smallest | 96 | 55 |

## Development

```sh
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
.venv/bin/ruff check . && .venv/bin/ruff format --check .
```

`python -m pdf_squeeze --selftest IN.pdf OUT.pdf [high|balanced|smallest]` compresses without the window.

## Building

The Windows build runs on GitHub Actions (`.github/workflows/build.yml`).
It lints, tests, builds a one-folder PyInstaller app, smoke-tests the built `.exe`, captures screenshots of the window, and uploads `PDFSqueeze-win64.zip`.

One-folder rather than one-file is deliberate.
A one-file exe unpacks DLLs into `%TEMP%` every time it starts, which locked-down PCs often block.

The app icon is generated by `tools/make_icon.py`.
